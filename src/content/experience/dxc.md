# Analista Funcional - DXC Technology

Desarrollo de aplicaciones web J2EE para cliente "la Caixa", en aplicaciones inmobiliarias, bancarias, tienda online.
Análisis y creación de documentación, tanto funcional como técnica (propuestas de solución, diseños técnicos,..)
Supervisión de pequeños equipos de desarrollo (5 personas) y acostumbrado a contacto directo con cliente.
Implementación de cambios, gestión de incidencias y administración de base de datos Oracle y traspaso de datos por migración de maquinas (Oracle 9i a 11g).
Uso de frameworks como Struts, y otros propios de cliente (AIS-Intranet, ABSIS, ABSIS-Cloud).
Creación y consumo de servicios web SOAP y REST.


## Contexto de la Empresa

DXC Technology es una empresa líder en servicios de TI que ofrece soluciones innovadoras a clientes en todo el mundo. Entre sus multiples clientes se encuentra "la Caixa", una de las principales entidades financieras de España, para la cual he participado en diversos proyectos de negocio relacionados con tienda online, prestamos y morosidad.

## Responsabilidades

- Desarrollo de propuestas técnicas y funcionales para nuevos proyectos
- Análisis de requisitos y diseño de soluciones adaptadas a las necesidades del cliente
- Coordinación y supervisión de un equipo de 5 desarrolladores
- Gestión de incidencias y soporte post-despliegue
- Mantenimiento y mejora continua de aplicaciones existentes
- Soporte para equipos externos y coordinación con proveedores
- Administración y optimización de bases de datos Oracle, incluyendo migraciones por cambios de entorno
- Desarrollo de utilidades genéricas para mejorar la eficiencia del equipo
- Optimización de rendimiento en entorno batch, especialmente en mejora de planes de ejecución en Oracle
- Code reviews y mentoring a desarrolladores junior

## Logros Destacados

### Migraciones de entorno
- Actualización y migraciones de Oracle de version 12 a 19
- Gestión de vulnerabilidades en entorno batch y migración a nueva versión de ALM
- Aportación al equipo de desarrollo Caixa para uso de entorno VSCode con profiles especificos y uso de devContainers para estandarizar entornos de desarrollo
- Resultado: mejora en satisfacción del developer y acelaración en tiempos de desarrollo debido a la extensiones y herramientas de VSCode

### Mejora de rendimiento en backend
- Estudio y mejora de consultas SQL en Oracle para optimización de procesos batch
- Analisis de codigo para evitar alto uso de CPU y memoria en servidores de produccion
- Resultado: reducción de tiempos de ejecución en procesos batch críticos en un 50%

### Otros
- Mantener como principal punto de backend en la tienda Online de Caixabank durante años, debido a la estabilidad y calidad del código entregado, obteniendo la confianza del cliente.
- Legacy: gestionar la parte fronted (Intranet) donde se usaban tecnologías antiguas como Struts y JavaScript puro, manteniendo la estabilidad y realizando mejoras incrementales. Se implementaron nuevas funcionalidades con Ajax para mejorar la experiencia de usuario.

## Stack Tecnológico

- **Framework**: J2EE Spring (Spring batch, Spring MVC)
- **Build Tools**: Pipeline con Maven y Jenkins
- **Backend**: Java, Spring Boot
- **Tools**: Eclipse, Toad, Postman, SoapUI
