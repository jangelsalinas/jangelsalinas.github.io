# Practicas - Memory Set (Esprinet)

Desarrollo en PL/SQL en Oracle Portal, mediante el uso de portlets, para el portal web de la compañía.
Desarrollo de aplicaciones de escritorio en Visual Basic 6, para uso de comerciales.


## Contexto de la Empresa

Memory Set es una empresa dedicada a la distribución de componentes y accesorios tecnológicos. Se caracteriza por ofrecer soluciones personalizadas tanto para particulares como para empresas, destacando por su atención técnica especializada y su compromiso con la calidad del servicio.

## Responsabilidades

- Desarrollo de portlets personalizados en Oracle Portal para mejorar la funcionalidad del portal web de la empresa.
- Creación y mantenimiento de procedimientos almacenados en PL/SQL para optimizar la gestión de datos.
- Desarrollo de aplicaciones de escritorio en Visual Basic 6 para automatizar tareas comerciales.

## Stack Tecnológico

- **Framework**: Oracle Portal
- **Tools**: Toad for Oracle, SQL*Plus
- **Lenguajes**: PL/SQL, Visual Basic 6
